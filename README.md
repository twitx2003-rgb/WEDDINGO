**הרעיון:** אתה מצלם את הדפים מהשיעור. **Claude Code עצמו** קורא את כתב היד, מתמלל, ובונה לכל הרצאה סיכום עם:
- 📝 **תמלול נאמן** של הדפים
- 💡 **הרעיון הכללי** — מה הנושא ולמה הוא קיים
- 🧠 **ההיגיון והאינטואיציה** — למה זה עובד
- 🛠️ **שיטות פתרון לתרגילים** — צעד-אחר-צעד עם דוגמה
- 🔑 **מושגי מפתח** ו-❓ **שאלות לתרגול עצמי**

בלי שרת, בלי build, ו**בלי API בתשלום** — מנוע ה-AI הוא Claude Code שכבר במנוי שלך.

## איך מוסיפים הרצאה

**דרך א׳ — מסך הסטודיו (מומלץ):** לחץ על **＋ סטודיו** בראש האתר. שם אפשר ליצור מחברת חדשה (שם, סמסטר, צבע), להעלות את צילומי הדפים, ולסמן בדיוק **אילו** דפים לנתח ובאיזה סדר. בסיום:
- בהרצה מקומית ב-Chrome/Edge: **"שמור לפרויקט"** כותב את הדפים ישירות ל-`inbox/` (כולל `inbox/job.json` שמגדיר את המשימה).
- בכל דפדפן אחר / בטלפון: **"ייצוא משימה"** מוריד את הקבצים; שים אותם ב-`inbox/`.
- ואז אמור ל-Claude: **"תעבד את הדפים"**.

**דרך ב׳ — ישירות:** שים צילומים ב-[`inbox/`](inbox/) או הדבק אותם בצ'אט עם Claude, ואמור **"תעבד את הדפים"**.

בשני המקרים Claude מתמלל, כותב את הסיכום, מעביר את התמונות למקומן, מעדכן את המניפסט, ודוחף — וההרצאה מופיעה באתר.

## הרצה מקומית

פתיחה ישירה של הקובץ ב-`file://` **לא** תעבוד (הדפדפן חוסם `fetch`). מריצים שרת סטטי קטן:

```bash
python3 -m http.server 8000
```

ואז פותחים <http://localhost:8000/>.

## פרסום ל-GitHub Pages (חינם)

1. ב-GitHub: **Settings → Pages**.
2. תחת *Source* בחר **Deploy from a branch**.
3. בחר את הברנץ' `claude/lecture-notes-study-site-lwwsja` (או `main` אחרי מיזוג) ותיקייה `/ (root)` → **Save**.
4. הכתובת תהיה `https://<שם-המשתמש>.github.io/WEDDINGO/`.

> **הערה:** ל-GitHub Pages בחינם צריך שהריפו יהיה **ציבורי**. האתר משתמש בנתיבים יחסיים בלבד, כך שהוא עובד גם תחת subpath של Pages וגם מקומית.

## מבנה הפרויקט

```
index.html            אפליקציית עמוד-יחיד (ניתוב hash)
css/style.css         כל השפה העיצובית (טוקנים ב-:root) + סגנונות הדפסה
css/fonts/            Frank Ruhl Libre + Heebo (מוטמעים, לא CDN)
js/app.js             ראוטר + רינדור Markdown + KaTeX + חיפוש + לייטבוקס
js/vendor/            marked + KaTeX (מוטמעים — עובד גם בלי אינטרנט)
content/manifest.json מקור האמת: קורסים ← הרצאות
content/courses/<course-id>/<lecture-id>/lecture.md + scans/
inbox/                צילומים גולמיים שממתינים לעיבוד
.claude/skills/process-notes/   ההוראות ל-Claude לעיבוד דפים
```

התוכן הנוכחי כולל **הרצאת דמו אחת** (ערכים עצמיים) שמדגימה את המבנה — אפשר למחוק אותה אחרי שמוסיפים הרצאות אמיתיות.
