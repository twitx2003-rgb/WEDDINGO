**הרעיון:** אתה מצלם את הדפים מהשיעור. **Claude Code עצמו** קורא את כתב היד, מתמלל, ובונה לכל הרצאה סיכום עם:

בלי שרת, בלי build, ו**בלי API בתשלום** — מנוע ה-AI הוא Claude Code שכבר במנוי שלך.

## איך מוסיפים הרצאה

**דרך א׳ — אוטומטי לגמרי (מומלץ):** לחץ **＋ סטודיו** בראש האתר, צור/בחר מחברת, העלה את צילומי הדפים, סמן אילו דפים לנתח, ולחץ **"✨ שלח לניתוח"**. הדפים נדחפים ל-GitHub, **Claude מנתח אותם אוטומטית** (דרך GitHub Actions), והסיכום מופיע באתר תוך דקות — בלי שום פעולה נוספת. דורש **הגדרה חד-פעמית** (ראה למטה).

**דרך ב׳ — ידני:** בסטודיו, "שמור מקומית" (Chrome/Edge, בהרצה מקומית) או "ייצוא" מורידים את הקבצים ל-`inbox/`; ואז אמור ל-Claude בסשן **"תעבד את הדפים"**. אפשר גם פשוט להדביק צילומים בצ'אט עם Claude.

בכל המקרים Claude מתמלל, כותב את הסיכום, מעביר את התמונות, מעדכן את המניפסט ודוחף — וההרצאה מופיעה באתר.

## ⚙️ הגדרה חד-פעמית לניתוח האוטומטי

כדי ש"שלח לניתוח" יעבוד, צריך שני דברים (פעם אחת):

### 1. טוקן של Claude ל-GitHub Actions (מנוע הניתוח)
במחשב שבו מותקן Claude Code, הרץ:
```bash
claude setup-token
```
זה מייצר טוקן OAuth (משתמש במנוי שלך — **בלי עלות API**). העתק אותו, ואז ב-GitHub:
**Settings → Secrets and variables → Actions → New repository secret**
- **Name:** `CLAUDE_CODE_OAUTH_TOKEN`
- **Secret:** הטוקן שהעתקת

### 2. טוקן שמאפשר לאתר להעלות דפים
צור **Fine-grained Personal Access Token**: <https://github.com/settings/tokens?type=beta>
- **Repository access:** רק הריפו `WEDDINGO`
- **Permissions → Repository → Contents:** **Read and write**

ואז באתר → **＋ סטודיו** → פתח **"⚙️ חיבור אוטומטי ל-GitHub"** → הדבק את הטוקן → **שמור חיבור**.

> 🔒 **אבטחה:** הטוקן הזה נשמר **רק בדפדפן שלך** (localStorage) ונשלח אך ורק ל-GitHub. הוא מוגבל לריפו אחד עם הרשאת כתיבת-תוכן בלבד. מומלץ לתת לו תוקף מוגבל (למשל 90 יום).

**איך זה עובד מתחת למכסה:** "שלח לניתוח" דוחף את הדפים ואת `job.json` ל-`inbox/<הרצאה>/`. הדחיפה מפעילה את `.github/workflows/process-notes.yml`, שמריץ את Claude, מנתח, כותב את הסיכום ודוחף — ו-Pages מתעדכן אוטומטית.

## הרצה מקומית

פתיחה ישירה של הקובץ ב-`file://` **לא** תעבוד (הדפדפן חוסם `fetch`). מריצים שרת סטטי קטן:

```bash
python3 -m http.server 8000
```

ואז פותחים <http://localhost:8000/>.

## פרסום ל-GitHub Pages (חינם)

1. ב-GitHub: **Settings → Pages**.
2. תחת *Source* בחר **Deploy from a branch**.
3. בחר את הברנץ' `claude/lecture-notes-study-site-lwwsja` (או `main` אחרי מיזוג) ותיקייה `/ (root)` → **Save**.
4. הכתובת תהיה `https://<שם-המשתמש>.github.io/WEDDINGO/`.

> **הערה:** ל-GitHub Pages בחינם צריך שהריפו יהיה **ציבורי**. האתר משתמש בנתיבים יחסיים בלבד, כך שהוא עובד גם תחת subpath של Pages וגם מקומית.

## מבנה הפרויקט

```
index.html            אפליקציית עמוד-יחיד (ניתוב hash)
css/style.css         כל השפה העיצובית (טוקנים ב-:root) + סגנונות הדפסה
css/fonts/            Frank Ruhl Libre + Heebo (מוטמעים, לא CDN)
js/app.js             ראוטר + רינדור Markdown + KaTeX + חיפוש + לייטבוקס
js/vendor/            marked + KaTeX (מוטמעים — עובד גם בלי אינטרנט)
content/manifest.json מקור האמת: קורסים ← הרצאות
content/courses/<course-id>/<lecture-id>/lecture.md + scans/
inbox/                צילומים גולמיים שממתינים לעיבוד
.claude/skills/process-notes/   ההוראות ל-Claude לעיבוד דפים
```

התוכן הנוכחי כולל **הרצאת דמו אחת** (ערכים עצמיים) שמדגימה את המבנה — אפשר למחוק אותה אחרי שמוסיפים הרצאות אמיתיות.
