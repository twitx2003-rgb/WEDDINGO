# עיבוד דפי הרצאה → סיכום מובנה

מטרה: להפוך צילומי כתב יד לעמוד הרצאה מלא באתר. עובדים לפי השלבים בסדר, ולא מדלגים על עדכון ה-manifest ועל ה-push.

## 1. טריגר
- המשתמש אומר "תעבד את הדפים" / "תסכם" / דומה, **או**
- קיימות תמונות ב-`inbox/`, **או**
- המשתמש הדביק תמונות בצ'אט.

## 0. יש `inbox/job.json`? (מסך הסטודיו) — מסלול מהיר
אם קיים `inbox/job.json` — **זהו המקור המוסמך, אין צורך לנחש**. הקובץ נוצר על ידי מסך הסטודיו של האתר ומכיל את הקורס, ההרצאה והדפים המדויקים. פעל כך ודלג על שלבי הסיווג (3):
1. קרא את `inbox/job.json`. הוא נראה כך:
   ```json
   { "course": { "id": "calculus-2", "name": "חשבון 2", "semester": "...", "color": "b", "isNew": true },
     "lecture": { "id": "2026-07-20-integrals", "title": "אינטגרלים", "number": 3, "date": "2026-07-20" },
     "pages": ["page-01.jpg", "page-02.jpg"] }
   ```
2. אם `course.isNew` — צור את הקורס ב-`manifest.json` (עם ה-id/שם/סמסטר/צבע הנתונים). אחרת השתמש בקורס הקיים.
3. **קרא ונתח רק** את הקבצים המופיעים ב-`pages`, **בסדר הזה**. הם כבר בשמות `page-NN` בתוך `inbox/`.
4. המשך לשלבים 4–8 (תמלול, סיכום, פעולות קבצים) עם היעד מה-job — בלי לשאול קורס/הרצאה.
5. **מחק את `inbox/job.json`** אחרי סיום, וכלול את המחיקה באותו קומיט.

אם **אין** `job.json` — המשך בזרימה הרגילה למטה (זיהוי מהתמונות / שאלה למשתמש).

## 2. קליטה
1. `ls inbox/` — רשום את כל התמונות (jpg/jpeg/png/webp/heic/svg). אם המשתמש הדביק בצ'אט, השתמש בהן.
2. **קרא כל תמונה** עם כלי Read כדי לראות את התוכן בפועל.
3. אם יש כמה הרצאות בערבוביה — קבץ דפים לפי רצף/נושא, והצג למשתמש את הקיבוץ המשוער לאישור קצר לפני שממשיכים.

## 3. סיווג (קורס + הרצאה)
1. קרא `content/manifest.json` לרשימת הקורסים הקיימים.
2. נסה להסיק קורס, כותרת, תאריך ומספר הרצאה מכותרות הדפים/התוכן.
3. אם לא ודאי — שאל את המשתמש שאלה **אחת** קצרה (הצע את הקורסים הקיימים + אפשרות "קורס חדש").
4. קורס חדש → בקש שם עברי, וצור `id` = slug ASCII (למשל `calculus-2`). בחר `color` פנוי מבין `a`–`f`.
5. `id` של הרצאה = `YYYY-MM-DD-topic-slug` (ASCII). אם אין תאריך ודאי — השתמש בתאריך שהמשתמש נותן או במספר ההרצאה.

## 4. תמלול נאמן
תחת `## תמלול הדפים`, סעיף-משנה `### עמוד N` לכל דף, בסדר הקריאה:
- תעתק **מה שכתוב**, כולל הסימונים של הכותב. אל "תשפר" בשלב הזה.
- המר מתמטיקה בכתב יד ל-KaTeX (`$...$` / `$$...$$`).
- מילה/ביטוי לא קריא → `[לא ברור: הניחוש הטוב ביותר?]`. אל תמציא.

## 5. יצירת הסיכום
כתוב את שאר הסעיפים, **מעוגנים בחומר המתומלל** (מותר להוסיף הקשר סטנדרטי של הקורס, אסור לסתור את הדפים). סדר קבוע:
```
# <כותרת ההרצאה>
## תמלול הדפים
## הרעיון הכללי          ← מה הנושא ולמה הוא קיים (פסקה-שתיים)
## ההיגיון והאינטואיציה   ← "למה זה עובד", בשפה פשוטה + תמונה מנטלית
## שיטות פתרון לתרגילים   ← שיטה ממוספרת + דוגמה שלב-אחר-שלב + טעויות נפוצות
## מושגי מפתח            ← רשימת bullet של הגדרות קצרות
## שאלות לתרגול עצמי      ← שאלות, כל פתרון בתוך <details><summary>פתרון</summary>…</details>
```
> חשוב: כותרות ה-`##` הן בדיוק אלה — ה-JS של האתר בונה מהן את ניווט הצד, וסעיף "תמלול הדפים" מקופל אוטומטית.

## 6. פעולות קבצים
```
mkdir -p content/courses/<course-id>/<lecture-id>/scans
# העבר כל תמונה מ-inbox עם שם רץ, בסדר הקריאה:
git mv inbox/<src> content/courses/<course-id>/<lecture-id>/scans/page-01.jpg   # וכו'
```
- כתוב `content/courses/<course-id>/<lecture-id>/lecture.md`.
- עדכן `content/manifest.json`: הוסף/עדכן את הקורס וההרצאה. אם ההרצאה כבר קיימת כ-`missing` — שנה ל-`ready` ומלא `scans` + `keywords`. שמור מיון הרצאות לפי `number`/`date`.

רשומת הרצאה ב-manifest:
```json
{ "id": "2026-07-15-eigenvalues", "title": "…", "number": 9, "date": "2026-07-15",
  "status": "ready", "scans": ["page-01.jpg", "page-02.jpg"],
  "keywords": ["…", "…"] }
```
`status`: `ready` (מוכן) · `draft` (תומלל אך הסיכום חלקי) · `missing` (הרצאה ידועה בלי חומר — placeholder). 3–6 `keywords` למנוע החיפוש.

## 7. אימות
- `python3 -m json.tool content/manifest.json` — JSON תקין.
- ודא שכל `$`/`$$` מאוזנים ב-`lecture.md`.
- אם זמין דפדפן: הרץ `python3 -m http.server 8000` ובדוק את עמוד ההרצאה החדש (הנוסחאות מרונדרות, אין שגיאות console/404).

## 8. קומיט + push
קומיט יחיד עם הסריקות + `lecture.md` + `manifest.json`:
```
git add -A
git commit -m "content: <שם הקורס> — <כותרת ההרצאה>"
git push -u origin <הברנץ' הנוכחי>
```

## 9. מקרי קצה
- **הוספת דפים להרצאה קיימת**: הוסף `### עמוד N` בהמשך התמלול, הרחב/רענן את סעיפי הסיכום, הוסף סריקות והמשך את מספור ה-`page-NN`.
- **דף שלם לא קריא**: תעד `[לא ברור: העמוד כולו לא קריא]` ובקש מהמשתמש צילום חד יותר.
- **HEIC**: המר ל-jpg אם יש כלי (`magick`/`sips`/`heif-convert`); אחרת שמור והערה שדפדפנים עלולים לא להציג HEIC — עדיף להמיר.
- **תמונה שאינה דף לימוד**: שאל את המשתמש לפני עיבוד.
