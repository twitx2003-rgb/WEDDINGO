# 📥 תיבת הדואר הנכנס

שים כאן צילומים של דפי ההרצאה/השיעור (jpg, png, webp…), ואז בקש מ-Claude Code:

> **"תעבד את הדפים"**

Claude יקרא את כתב היד, יתמלל, יבנה סיכום מובנה (רעיון כללי, היגיון, שיטות פתרון), יעביר את התמונות לתיקיית ההרצאה, יעדכן את המניפסט וידחוף — והכל יופיע באתר.

אפשר גם פשוט להדביק את התמונות ישירות בצ'אט.

*(הקובץ הזה נשאר כאן רק כדי לשמור על התיקייה. אפשר להתעלם ממנו.)*
